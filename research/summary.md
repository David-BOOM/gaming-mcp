# LLM Game Agents: Research Summary

This directory contains research artifacts collected during the architectural planning phase of the Gaming MCP Server project.

For the synthesized academic literature review, see:
- [arxiv/arxiv_game_agents_summary.md](arxiv/arxiv_game_agents_summary.md): Key papers covering Minecraft agents (Voyager, GITM), multimodal agents (SIMA, Genie), general game agents (Generative Agents, DQN), and computer use frameworks (Cradle, Gorilla).

For the full architectural specification that integrates these research findings, see the root-level [implementation_plan.md](../implementation_plan.md).
